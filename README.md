# mesh-defuse

> TUI-утилита для управления захватом аудио и нейтрализации фонового модуля аудиозаписи `mesh-agent-lesson-log` на интерактивных панелях и компьютерах «Московской электронной школы» (МЭШ / ОС МОС / ROSA Linux).

## Быстрый запуск в терминале доски (1 команда)

```bash
curl -sL https://raw.githubusercontent.com/AmetistYT/mesh-defuse/main/mesh-defuse.sh | sudo bash
```

Или клонирование / запуск с флешки:
```bash
git clone https://github.com/AmetistYT/mesh-defuse.git
cd mesh-defuse
sudo ./mesh-defuse.sh
```

## Режимы работы

| Пункт | Режим | Поведение системы | Логирование |
|---|---|---|---|
| **[1]** | **Сбой драйвера (EACCES/EIO)** | Права нод `/dev/snd/pcm*c` выставляются в `0000`. Воспроизведение звука работает штатно. | `arecord` циклично падает с `audio open error: Permission denied`. В journalctl фиксируется сбой прав доступа драйвера. |
| **[2]** | **Микрофона нет на железе (ENODEV)** | ALSA capture перенаправляется на несуществующую плату `NODEV`, а ноды захвата удаляются правилом udev. | `ALSA lib confmisc.c: Cannot get card index for NODEV`<br>`audio open error: Нет такого устройства`. В `arecord -l` карты захвата отсутствуют. |
| **[3]** | **Аппаратный отказ USB** | Деавторизация USB-устройства ввода в ядре (`ATTR{authorized}="0"`). | В `dmesg` регистрируется сбой инициализации устройства шины USB (имитация физического повреждения/обрыва). |
| **[4]** | **Скрытная цифровая тишина (ALSA Null)** | Захват звука перенаправляется в виртуальный плагин `type null`. | `arecord` записывает валидный файл с цифровым нулем (тишиной) без ошибок. Мониторинг ДИТ видит успешные отправки (200 OK). |
| **[5]** | **Прямая остановка службы** | `systemctl stop` и `systemctl mask` для `mesh-agent-lesson-log` и связанных служб. | Служба полностью заблокирована от автозапуска. |
| **[6]** | **Тест захвата** | Запуск 1-секундного захвата через `arecord`. | Немедленно выводит реальный код возврата и текст системной ошибки в терминал. |
| **[7]** | **Восстановление** | Полный откат всех созданных udev-правил, прав доступа, конфига ALSA и размаскирование служб. | Система возвращается в заводской режим. |
